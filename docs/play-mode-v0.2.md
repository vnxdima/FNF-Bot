# ТЗ: Play Mode — сыграй свой чарт, v0.2

Дополнение к [chart-editor-bot-v0.1.md](chart-editor-bot-v0.1.md).

## Сценарий

1. После «✅ Готово» чарт сохраняется как «последний чарт» пользователя, появляется кнопка «▶️ Играть».
2. «▶️ Играть» → отдельное сообщение-игра: отсчёт «3…2…1», затем поле начинает «ехать»: бот перерисовывает его каждые ~1.5 с, верхняя строка с меткой ▶ — текущая.
3. Игрок тапает кнопки `← ↓ ↑ →` в момент, когда нота его дорожки оказывается на линии ▶.
4. По окончании (или «⏹ Стоп») — итог: идеально/хорошо/мимо/лишние тапы, точность %, ранг S/A/B/C/D.

## Оценка попаданий

- Засчитывается **время тапа** (callback), а не состояние картинки — картинка лишь подсказка.
- Дорожки цветные (как в FNF): ← 🟣, ↓ 🔵, ↑ 🟢, → 🔴. Сверху поля — цветная линия приёмников; ноты в поле и кнопки — тех же цветов. Правило для игрока: «нота доехала до своего цвета — жми кнопку этого цвета».
- **Аккорды:** Telegram не позволяет нажать две inline-кнопки одновременно, поэтому тап по любой дорожке аккорда засчитывает все ноты этой строки разом (оценка тапа применяется ко всем).
- Темп: строка = `PLAY_STEP_MS` = 1000 мс (1 нота/с). Старт нот через `LEAD_MS` = 2000 мс после «GO!».
- Поле перерисовывается синхронно с шагом: один кадр = сдвиг ровно на одну строку (частота 1 кадр/с — потолок editMessageText; плавнее в тексте невозможно, плавная анимация — задача Mini App).
- Линия ловли одна: `▶⚪⚪⚪⚪◀ ЛОВИ` — пустые приёмники ⚪; доехавшая нота загорается своим цветом прямо в линии. Пойманная — гаснет.
- Окна: ±300 мс — «идеально» (✨), ±700 мс — «хорошо» (✅), дальше — мимо.
- Тап по дорожке без ноты в окне — «лишний тап» (💨), на точность не влияет, показывается в итоге.
- Точность = (perfect + 0.5·good) / всего нот. Ранги: S ≥95, A ≥85, B ≥70, C ≥50, иначе D.
- Каждая нота засчитывается один раз; из нескольких кандидатов выбирается ближайшая по времени.

## Ограничения формата (осознанные)

- Без звука и плавной анимации — это потолок текстового Telegram; настоящий геймплей будет в Mini App (v1.x).
- Перерисовка — 1 кадр/с, синхронно с шагом строки. Сетевая задержка тапов компенсируется широкими окнами.
- Одна игра на пользователя; повторный «Играть» перезапускает, «Новый чарт» прерывает игру.
