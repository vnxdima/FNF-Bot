# Роадмап FNF-Bot

> Источник истины по плану проекта. После инициализации wiki эта страница переезжает туда (Home).

## ✅ Сделано

- **v0.1 — Chart Editor** (бот): сообщение-редактор, 4 дорожки, toggle-ноты, аккорды, окно 15 строк
- **v0.2 — Play mode**: сыграй свой чарт; цветные дорожки FNF, одна линия «ЛОВИ», ловля аккорда одним тапом, профили темпа 📱/🖥
- **v0.3 — Мини-игры**: Саймон говорит (память), Тайм-атака (реакция), Баттл с боссом (тактика)
- **Инфраструктура**: деплой на сервер (Docker, restart unless-stopped), токен только в env

## 🔨 В работе

- **v1.0 — Mini App** ([#3](https://github.com/vnxdima/FNF-Bot/issues/3)): платформа игр на GitHub Pages
  - Первая игра: **FNF-раннер** — персонаж перепрыгивает ноты (аналог динозаврика Chrome)
  - Хаб с карточками игр («Скоро» для будущих)
  - Кнопка запуска из бота

## 🗓 Дальше (обсуждается)

- Таблица лидеров тайм-атаки и раннера (Postgres уже на сервере)
- Персистентность чартов (сейчас — в памяти процесса, теряются при рестарте)
- Экспорт чарта в формат FNF JSON (`sectionNotes`)
- Музыка: загрузка аудио, автоопределение BPM, чарт под песню
- GIF-превью чарта со спрайтами стрелок
- Совместное редактирование / челленджи в группах

## Правила проекта

- `main` — только для владельца; Claude работает в ветках `claude_*`
- Mini App публикуется из ветки `gh-pages`
- Токены — только в env/локальных файлах, никогда в репозитории
- Задачи — в GitHub Issues, прогресс отмечается чекбоксами
